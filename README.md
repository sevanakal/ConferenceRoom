# ConferenceRoom

Açık kaynak, ücretsiz konferans salonu yönetim sistemi: salon krokileri, etkinlikler ve rezervasyonlar.
ASP.NET Core ve MySQL ile web öncelikli geliştirilir; ileride mobil uygulama aynı API'yi kullanacak.
