# ConferenceRoom

Açık kaynak, ücretsiz konferans salonu yönetim sistemi: salon krokileri, etkinlikler ve rezervasyonlar.
ASP.NET Core ve MySQL ile web öncelikli geliştirilir; ileride mobil uygulama aynı API'yi kullanacak.

## Klasörler

| Klasör | İçerik |
| --- | --- |
| [`salon-kroki-editoru/`](salon-kroki-editoru/) | Salon krokisi editörünün prototipi. `index.html` dosyasını tarayıcıda açarak deneyebilirsiniz. |
| [`koltuk-secimi/`](koltuk-secimi/) | İzleyicinin krokiden koltuk seçip bilet aldığı ekranın prototipi. `index.html` dosyasını tarayıcıda açarak deneyebilirsiniz. |
| [`src/`](src/) | Uygulamanın kendisi: ASP.NET Core çözümü, Docker kurulumu. Çalıştırma adımları [src/README.md](src/README.md) içinde. |
